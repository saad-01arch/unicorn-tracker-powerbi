# Global Unicorn Tracker — Power BI Capstone

A 3-page Power BI dashboard analysing 5,000 unicorn companies 
across 30 countries, answering 5 key business questions.

## Questions answered
1. Which countries dominate the unicorn ecosystem?
2. Which sectors produce the most unicorns?
3. How has unicorn creation trended year-over-year?
4. How long does it take to become a unicorn?
5. What is the survival rate of unicorns?

## What was built
- 5,000 row dataset across 5 tables
- 21 DAX measures
- 3 dashboard pages with slicers
- 10-slide capstone presentation

## Tools used
Power BI Desktop · DAX · Power Query
